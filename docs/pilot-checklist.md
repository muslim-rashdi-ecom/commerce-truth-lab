# Pre-pilot Authorization Checklist

1. [ ] Merchant has signed data-sharing authorization
2. [ ] Data is pseudonymized (no real customer PII)
3. [ ] Workspace is isolated (no cross-merchant data)
4. [ ] Deletion policy agreed
5. [ ] Scope of audit defined in writing
6. [ ] Report sharing permissions defined
7. [ ] Currency configuration confirmed
8. [ ] Grace periods for COD confirmed by merchant
